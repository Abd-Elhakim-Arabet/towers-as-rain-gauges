# Cities ready to watch

Béjaïa, Constantine and Tébessa, already set up (terrain, land cover, soil, tower sites, flash-flood rain thresholds).
On the first start of the server they are copied into `data/live/` and watched straight away, so the live watch and
its drill work on a new install without the long first set-up (several hours on a computer without a GPU).

Removing one of these cities on the page removes it for good; it is not copied again. Data: Copernicus DEM, ESA
WorldCover, HYSOGs soil, OpenStreetMap masts (ODbL) and OpenCelliD sites (CC BY-SA 4.0); see docs/DATA.md.
